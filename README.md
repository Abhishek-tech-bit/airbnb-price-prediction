# 🏠 Airbnb Price Prediction — New York City

## 📌 Project Overview
This project uses Machine Learning and Linear Regression to predict Airbnb listing prices in New York City.

Completed as **Minor Project 2** for the UNLOX Job Bridge Course in Artificial Intelligence.

## 🎯 Objectives
- Explore the dataset using Pandas.
- Identify and handle missing values.
- Analyze extreme values using boxplots.
- Encode categorical variables using One-Hot Encoding.
- Train a Linear Regression model.
- Evaluate model performance.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## ⚙️ Workflow
1. Data exploration
2. Data cleaning and preprocessing
3. Outlier analysis
4. Feature selection and encoding
5. Train-test split (80:20)
6. Linear Regression model training
7. Predictions and evaluation
8. Visualization of actual versus predicted prices and residuals

## 📊 Model Performance

| Metric | Result |
|---|---:|
| R² Score | 0.4754 |
| MAE | $36.53 |
| RMSE | $49.45 |

The model explains approximately 47.54% of the variation in prices in the test dataset. These results provide a baseline for future improvements.
